# VisitReady for Android

Download the latest app: [VisitReady.apk](https://github.com/albaraaroury190-tech/visitready-android/releases/latest/download/VisitReady.apk)

To install, open the file on your Android phone and allow installing apps from your browser when asked.
This is a test build for trying out the app. It is signed with a development key, not a Play Store key.
